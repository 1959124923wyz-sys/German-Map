## 严格的统计边界

1. **财政收支**是某期间的流量；**年末债务**和**财政储备**是存量。用同一个“财政好坏评分”混合它们会误导。
2. **城市预算独立决算、城市集团合并报表、县本级预算、县域内所有市镇合计、规划地区汇总**是不同统计主体。同一城市不同指标只能有条件地比较；在跨州执行全国排名前必须统一会计制度与主体范围。
3. 图林根2025人均债务若官方字段刊载短划线，应保持空值，不得填0。石荷州15区在当前登记文件中全部缺人均值，**不是零债务**。
4. 原有行政区边界在哥廷根/艾森纳赫/哈瑙存在年份变化。只有核实新版区划与各地区AGS的一致性后才能执行全国县级涂色。
5. R11历史下载清单记录当时未获得的原始文件；**R12已成功取得上述3份全国原件**。其他来源仍需核实。`source/national_official_bulk_inventory.csv` 区分 `source_verified` 与 `binary_not_ingested`，不能算为已经拥有数值。
6. 所有数据应与B线的170条紧缩事件保持独立，不能以事件数量推导地区财务风险，避免重复记录或重复计算金额。
