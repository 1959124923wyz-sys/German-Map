# 05 移民｜已有AZR历史数据州级明细（2026-10-11）

原始 `topics/immigration/data/azr-records.js` 已包含16州×2018—2025年8个年末官方AZR人数，外加全国同口径合计。此前这128个州年数值只能通过年度下拉和小折线图逐个观察；不能直接查阅完整年份及相邻年份的登记差额。

**此次改造**：
- 全国初始只有一项官方全国数与地图，16州排名默认折叠；直接点击官方地图州形仍进入同一州详细页。
- 选择州后，显示2018—2025年8个AZR官方原始登记人数的逐年表（默认折叠），点某一年自动切换地图年份与州统计，再切回2025。
- 在表中明示差额是**登记册人数存量变化**，不是净入境人数、新增移民人数、非法居留或犯罪。
- 2025年AZR州登记人数与居民人口推算体系的州级外国籍占比严格保持独立，只有人数视图才显示AZR同口径年度明细。
- 已核实4个州25县官方县级资料与地图点击保持不变，不为其他12州推算县级值。全部年份数据来自原归档，未添加外部猜测。

验收：`topics/immigration/tests/smoke_leaflet.py` 两种实际Chromium尺寸验证默认折叠、16州展开、柏林2018/2025明细、石荷州15县地图和原有模式切换。修改不影响其他板块数据。
