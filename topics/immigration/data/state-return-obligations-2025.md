# AZR 2025 · State-level return obligations / 离境义务

**文件**：`state-return-obligations-2025.json`

**官方原表**：[Deutscher Bundestag 21/4103](https://dserver.bundestag.de/btd/21/041/2104103.pdf)，2026-02-11，第21页，问题20的第一个州级表。日期：2025-12-31。

- **人口存量**，而不是2025年新发生的非法入境案件。
- **完全覆盖16州**，使用原始印刷表逐行录入，并计算交叉和检验。
- 官方指标分别为总负有离境义务、其中持有Duldung、其中无Duldung；两个子项之和等于总数。
- `Duldung` 是暂缓遣返，表示仍负有离境义务，但执行存在法律或实际障碍，不是对犯罪行为的判定。
- 地图采用州级统计，不建立未公布的县、市数据。AGS两位州码、DE-ISO编码与项目只读州边界的 `properties.id` 对应。
- 所有指标来自一张同期表，跨州绝对值可对照；没有州居民人口作分母，因此不将绝对人数标记为风险率。
- 离境义务时点存量与2025年遣返执行流量来自不同数据源，不应相除声称年度遣返成功率。
- 当前16州全覆盖，没有缺失记录；今后新增年份或地区必须以 `null` 标注未知，不得默认为0。
