# 09 工业 / 10 基建 / 11 住房｜全国—州—县市渐进式资料室（2026-10-11）

## 交互规则
1. **全国首屏**只显示独立指标的基本地图、当前统计口径/图例、简短介绍和最少控制；全国排行榜和完整事件列表默认折叠，工厂/工程标点默认关闭。
2. **点击联邦州或选择定位州**打开同一侧栏的“州资料室”，页签用于切分已采集但此前被隐去的数据。每次改州回到概况页，不把历史标签内容漏给下一州。
3. **县市及企业/工程**为下一层，显示仅在当地有效的原始记录与时间/证据；全国返回按钮清理地区、选中记录与页签。页签有角色、aria-selected、左右箭头/Home/End 键盘操作，公共实现为 `js/core/region-dossier.js`，样式 `css/region-dossier.css`。
4. 不新增综合评分、推断岗位实际失业人数、跨年份混合排名、缺失补零，也不将近似标点宣传为精准厂址。

## 发布保护/质量闸
- 不改变研究原始数据，只引用已归档的CSV/JSON，新增聚合均在客户端按明确地区和分母完成。
- `node --check js/core/region-dossier.js` 与原三主题源数据核验保留。
- GitHub Actions `three-topics-pr-check.yml` 内进行实际Chromium桌面和390px手机回归：国家状态、州切换、页签、研究数据、县市搜索、返回。
- `scripts/validate_site_assets.py` 用于检查所有新CSS/JS路径的可达性；主站 Pages 继续只有原来的部署工作流。
- 如果CI不通过，保留本次独立分支和PR，不能视作生产上线。
