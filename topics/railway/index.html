数据来源与颜色判定

2026年9月 DB Timetables API 历史停站数据，经 Piet Brömmel 汇编；轨道依据 DB InfraGO 官方线路几何及公里标匹配。

在“延误或取消”模式下，若下游站晚点至少6分钟的比例达到40%，或到发停靠取消标记涉及比例达到8%，标红；达到25%或4%则标橙。单指标模式沿用对应门槛。阈值是地图展示规则，并非德国铁路官方评级。

取消标记比例不是整趟列车取消概率；下游到站晚点不代表轨道本身造成了延误。不同车型/运营商品牌单独统计，未做乘客量加权，灰暗铁路不代表运行正常。
