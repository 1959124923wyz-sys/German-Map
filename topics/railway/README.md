# BahnMonitor · 德国铁路运行专题

这是 German-Map 与暴力、财产、毒品、移民、环保平级的铁路专题。

## 页面

- `index.html`：复用与主站一致的 OSM 街道底图、Leaflet 缩放、16州和县界及中文城市标签；根据仓库内原始 DB InfraGO 官方轨道 WGS84 线几何绘制**完整基础设施轨道网**（33,547个几何部件），叠加实际观测的绿／橙／红区间；默认区域列车（RE/RB）合并观测。通过 `overview.js` 按选中车类按需加载已发布的区间聚合数据分片，避免把全部运营商脚本同时加载。
- `js/rail-geometry.js`：铁路真实曲线解码、Mercator 投影、包围盒与距离计算；纯工具模块，不请求网络、不创建 UI。投影/选线算法的修改先跑 `tests/unit_core.cjs`。
- `js/rail-analysis.js`：RE/RB 同站间整数计数合并、两种统计分母、风险颜色和同色连续区间链；明确阻止不同路线、分叉或公里断裂拼接，避免将小段百分比求平均。
- `overview.js`：负责 Leaflet 地图、Canvas 绘制、加载调度、用户选择和侧栏更新。纯计算从上述模块调用，不再在大脚本内复制实现。
- `overview.js`：两个 Leaflet Canvas 绘图图层：基础设施全线和有运行观测的区间，避免上一版 4,218 区间 ×2 的 SVG 节点与大量监听器。官方轨道路径在浏览器内一次性解码并进行 EPSG:3857 投影；观察区段在切换筛选时**只重算等级、不重建 SVG 节点**；鼠标点击使用基于几何包围盒的空间桶索引，再以真实线段距离确认命中。
- `overview.css`：保留 German-Map 深色标题/侧栏、统计卡风格，地图区采用与移民、毒品、环保相同的浅色 OSM 街道图。
- `research.html`：完整保留原 v14 研究型仪表盘（包含原线路检索、基础设施和历史观测界面），仍使用 `js/app.js` 等旧版资源。
- `tests/smoke_overview.py`：桌面、手机、区域/长途/其他运营商三组切换、中文站名、热点排名、指标、样本门槛与详情的自动浏览器验收。CI：`.github/workflows/railway-map-smoke.yml`。

## 地图颜色规则（2026年9月）

线段依据历史列车停站配对表现分色，不归因于轨道故障。

- 红色：下游到站晚点达到6分钟的观测比例 **≥40%**，或者到发停靠取消标记涉及比例 **≥8%**。
- 橙色：对应比例 **≥25%** 或 **≥4%**，但未达到红色门槛。
- **绿色**：低于对应警示阈值的真实观测区间，也包括以较淡绿色呈现的无可比观测轨道；不能理解为官方认证的正常运行。**灰色**：未匹配到可靠观测、样本量未达门槛的基础设施网络；不代表这些线路运行正常。
- 图例直接标注数值范围：**仅晚点**为绿 <25%、橙 25%–<40%、红 ≥40%；**仅停靠取消**为绿 <4%、橙 4%–<8%、红 ≥8%。**综合**使用两项独立的“或”条件：绿为晚点 <25% 且取消 <4%；红为晚点 ≥40% 或取消 ≥8%；橙为有指标达到低门槛但未达到高门槛。两项的分母不同，**不计算也不展示虚假的统一百分比**。
- 每个方向性站间区间的最低样本门槛**固定为100个有效观测**，简洁页面不再提供样本量选择器。底图所有 33,547 个官方轨道几何部件（包括无运行匹配数据的路段）以较淡的绿色完整绘制，确保站间没有观测数据时铁路线仍按**原始官方曲线**可见。绿／橙／红线仅覆盖各类已匹配且样本足够的停站观测几何；不推测无数据的绿色底线的晚点率，不用连接两端点的**臆造直线**补缺。细节按 EPSG:3857 和 OSM 保持坐标一致，缩放时仅跳过显示面积小于像素阈值的中间顶点，原始几何从不改动。

## 来源与局限

- DB InfraGO 2026 官方铁路网 WGS84 线几何；DB Timetables API 在2026年9月的历史停站记录，经 Piet Brömmel 的 [Deutsche Bahn Data](https://github.com/piebro/deutsche-bahn-data) 汇编（CC BY 4.0）。
- 历史到站变更时间可包含预测值；观测是列车**下游站到站表现**，不是区间本身造成的晚点概率。
- 停靠取消标记不等于整趟列车取消、途中终止运行或旅客被滞留的确证。
- **界面仅有三个列车类别：**区域列车（RE/RB）、长途列车（ICE/IC/EC/FLX）和其他运营商（HLB/BRB/ERB/NWB/OE）。各组内依据官方线路编号、起终车站、方向和公里区间匹配后累计原始整数观测量，再计算比例；未匹配不同路段不可合并。其他运营商品牌与区域列车在实际运行服务上可能重叠，因此**不能跨类别加总，也不能作为全国车次占比**。
- 车站名用本地 `js/station-zh.js` 显示常用中文译名；原始德文站名始终保留。未经确认的小站不强行翻译。
- 没有被着色的线路不能理解为准点或没有问题；没有按旅客人数加权，也不构成运营商公平排名。
- 原始9月 Parquet、官方完整原始 CSV 和重算脚本仍以 v14 项目交接包另行保存，不发布到网站。

简洁地图首次点击彩色线段会选中同线路编号、同方向、同风险颜色、站间公里边界相接且无分叉的连续区段，使用**晚点次数/有效到站观测次数**及**停靠取消标记次数/计划配对次数**分别做原始整数合计，再计算比例；禁止把子区间百分比简单平均。连续区段可能重复包含同一列车在多个相邻站间的停站观测，因此展示的是**站间观测加权率**，不是独立整趟车的准点或取消概率。主面板仅呈现“准点率（晚点不足6分钟）”和“停靠取消标记率”，逐站、原始数量和德文站名收纳于可展开的二级详情。

旧版的总体数量统计保留在研究资料中；简洁页面将高关注榜单、研究方法收纳于折叠菜单。原始记录、100次纳入规则与数值警示门槛保持不变。

观察区间高关注榜单按是否超过门槛及相对阈值大小排序，仅用于寻找要关注的地点，不构成全国铁路运行质量的官方排名。

新版本不得修改已公布的事实数据来使地图“更红”。若调整警示阈值，应同步修改 `overview.js`、主页方法说明、本文件和浏览器烟雾测试。

- 公共页面启动依赖顺序：`js/rail-geometry.js` → `js/rail-analysis.js` → `overview.js`。不要将其与仍供 `research.html` 使用的旧版研究仪表盘脚本混合。
- `node topics/railway/tests/unit_core.cjs` 对数据统计、岔线合并约束、真实几何投影做无浏览器单元验证。

- `python topics/railway/tests/smoke_overview.py` 是桌面+手机真实浏览器回归，包括点选真实线路、官方几何、Canvas 图层数量、各车类加载及数值明细。
- `overview.css` 已移除旧版 SVG 视图、已下线参数卡与浮动说明相关的62组失效样式；研究版有独立 HTML 和样式，不应从研究版复制废弃规则回来。
- CI 与网站发布均会运行上述静态/纯计算检查；仅在合并/发布后检查全部成功方可视为完成。
- 保持实证源文件和统计口径不变；构建性能优化不得臆造没有观测数据的轨道段的准点率。
