# BahnMonitor · 德国铁路运行专题

这是 German-Map 与暴力、财产、毒品、移民、环保平级的铁路专题。

## 页面

- `index.html`：默认极简地图。深灰官方铁路线底图、红/橙实际观测较差区间，默认 RE；通过 `overview.js` 按选中车类按需加载已发布的区间聚合数据分片，避免把全部运营商脚本同时加载。
- `overview.css`：延续 German-Map 深色站点风格。
- `research.html`：完整保留原 v14 研究型仪表盘（包含原线路检索、基础设施和历史观测界面），仍使用 `js/app.js` 等旧版资源。
- `tests/smoke_overview.py`：桌面、手机、RE/RB/ICE 选择、指标、样本门槛和详情的自动浏览器验收。CI：`.github/workflows/railway-map-smoke.yml`。

## 地图颜色规则（2026年9月）

线段依据历史列车停站配对表现分色，不归因于轨道故障。

- 红色：下游到站晚点达到6分钟的观测比例 **≥40%**，或者到发停靠取消标记涉及比例 **≥8%**。
- 橙色：对应比例 **≥25%** 或 **≥4%**，但未达到红色门槛。
- 浅灰：有足够样本但低于上述阈值；深灰轨道底色：没有通过地理和样本量筛选。
- “仅延误”和“仅取消”使用各自门槛；默认组合模式是两项独立指标的**或条件**，不是推算的联合事件概率或加权风险评分。
- 默认每个方向性站间区间至少100个有效观测；筛选器可以提高至300/500。

## 来源与局限

- DB InfraGO 2026 官方铁路网 WGS84 线几何；DB Timetables API 在2026年9月的历史停站记录，经 Piet Brömmel 的 [Deutsche Bahn Data](https://github.com/piebro/deutsche-bahn-data) 汇编（CC BY 4.0）。
- 历史到站变更时间可包含预测值；观测是列车**下游站到站表现**，不是区间本身造成的晚点概率。
- 停靠取消标记不等于整趟列车取消、途中终止运行或旅客被滞留的确证。
- ICE/IC、RE/RB 与 HLB/BRB/ERB/NWB/OE 是相互独立的观测筛选，部分服务可能重叠，切勿把这些统计机械求和。
- 没有被着色的线路不能理解为准点或没有问题；没有按旅客人数加权，也不构成运营商公平排名。
- 原始9月 Parquet、官方完整原始 CSV 和重算脚本仍以 v14 项目交接包另行保存，不发布到网站。

新版本不得修改已公布的事实数据来使地图“更红”。若调整警示阈值，应同步修改 `overview.js`、主页方法说明、本文件和浏览器烟雾测试。
