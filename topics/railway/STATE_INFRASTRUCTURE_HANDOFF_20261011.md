# 07 铁路｜既有16州DB InfraGO资产资料室（2026-10-11）

## 来自已发布但几乎没有前台入口的统计

`topics/railway/data/data-core.js` 的 `DATA.states` 内有16州汇总字段，至少包括 `segments`、`length`、`elec_len`、`single_len`、`double_len`、`highspeed_len`、`unknown_speed_len`、`tunnels`、`bridges`、`crossings` 和 `ops`。站段主绘图已经使用DB InfraGO 33,547真实轨道线段，但地区基础设施数据此前没有用在公共铁路侧栏。

**重要：** `DATA.qa.track_section_km_not_unique_route_km=true`：源字段的长度是轨道方向/线轴分段数值的累计，**不是唯一物理线路营业公里**；某些桥梁等设施字段按分段记录累计，**不能直接断言为州内去重独立实体数量**。因此这组数据只能用作DB InfraGO源字段的州级资料，不冒称铁路运行好坏或安全检查排名。

## 实际发布改动

1. 全国首屏延续绿色完整线路骨架、客运RE/RB、ICE/IC及运营商选择，**不添加州级散点图或附加色阶**。
2. 在铁路侧栏增加默认折叠的“16州铁路基础设施资料室”。展开并选择州，提供“路网概况／轨道构成／工程设施”三页签，统一共用 `region-dossier.js` 和 `region-dossier.css`。
3. 展示该州原数据的分段条数、累计长度、电气化、单/双线、高速/速度未知，和桥梁/隧道/道口/运营地点的原始字段累计。每个页签都明示汇总粒度与不能推断的结论。
4. 选州后用已经加载的16州真实GeoJSON边界缩放地图；州界继续 `interactive:false`，不侵占乘客观测线路的点击空间。原地图的100观测门槛、橙红阈值、走廊统计、实际站间详情保持不变。
5. 点击地图上的“全国”按钮清空州资料室的当前选择，不影响既有客运观测的统计数据。
