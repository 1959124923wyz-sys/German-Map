# 06 环保｜州级来源档案与默认清爽地图交接（2026-10-11）

## 未被有效利用的信息
原始 `topics/environment/data/records.js` 含154条经过来源整理的记录，互斥主类：41行动、10政策、11组织/项目争议、92设施。每条可有真实结果、司法后续、经济影响证据和来源URL，原来主要靠154个全国事件点和折叠列表浏览。
经逐条字段盘点，**只有73条有 `state`（德文联邦州名）并能直接归州，覆盖11州。剩余81条不能仅凭定位坐标（如柏林议会）视为柏林事件**。

## 前端
- 全国首屏不显示154个密集事件标点，只保留完整统计分类、图例、官方OSM地图和一处「显示地图事件点」复选框；勾选才绘制与原来完全一致的154条图标，切换分类正常。
- 利用已有16州官方GeoJSON：点击州边界或使用州定位下拉，展开公共tab组件的州资料室：
  - **概览**：源档案中明确州归属条数、行动记录、设施、去重URL数量；0档案写作「未收集到」，不是事件不存在。
  - **地方档案**：本州明确归属的原始记录按日期排列，可按事件/主体/地点搜索，点开使用既有完整证据页面。
  - **进展与证据**：逐条读取 `outcome` / `measured_impact` / `limits` 与真实链接；未发布后续注明来源未确认，不推断已实施。
- 地图边界仍为官方真实州界，既有城市/县道参考线不改；不虚构所有81条政策和地点的所属州。

## 数据保护
- 原 `records.js` **一字未改**，所有154条原始信息仍可通过全国“记录列表”与图层复选框访问。
- `topics/environment/tests/validate_state_dossier.cjs` 以154/73/81及11州明确字段为发布闸。
- `topics/environment/tests/smoke_environment.py` 桌面和手机回归：全国默认0点、勾选后154点、五类筛选、政策点正确、点击州、北威22条、西南州0条、切回全国并访问原始来源。
- 保留只此一个Pages发布工作流及其他专题全部数据。恢复请从独立PR查看变更。

后续：只有在全国政策/设施有明确统计适用地域元数据时，才能为它们加州级归属；不使用点在柏林自动代表柏林地区。
